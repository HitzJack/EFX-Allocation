# EFX-Allocation
Designed a potential-guided swap algorithm to compute
EFX allocations for 3 agents under montonic valuations.
• Constructed counterexamples showing naive envy-transfer
schemes cycle indefinitely and that 2-cycle/3-cycle blocking
rules fail to ensure termination.
• Introduced a welfare potential Φ as a monotonic progress mea-
sure; proved every admitted swap strictly increases Φ.
• Verified convergence to EFX across 10,000+ randomized in-
stances (4–9 goods, all initial allocations) within 400 iterations,
with zero counterexamples
